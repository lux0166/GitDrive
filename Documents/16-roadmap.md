# 16 — Product Roadmap

## Phase 0 — Discovery / Technical Spike

Goal: prove the product thesis.

Deliver:
- project detector for 2–3 stacks;
- workflow IR;
- one runner;
- build artifact;
- local download;
- benchmark against manual pipeline setup.

**Exit criteria:** automatic workflow generation demonstrably reduces setup steps/time.

## Phase 1 — MVP

- local Git repository;
- users/auth;
- repository scan;
- generated workflow;
- runner scheduling;
- build/test/package;
- artifacts;
- release page;
- LAN download.

## Phase 2 — Team workflow

- PR/review;
- branch protections;
- secrets;
- runner groups;
- workflow templates/policies;
- logs/audit.

## Phase 3 — Delivery acceleration

- dependency cache/mirror;
- build cache;
- matrix builds;
- release automation;
- app catalog;
- update agent.

## Phase 4 — Intelligent platform

- adaptive workflow proposals;
- failure diagnosis;
- local AI code review;
- workflow optimization suggestions.

## Phase 5 — Advanced infrastructure

- multiple build nodes;
- artifact governance;
- signed releases;
- richer deployment targets;
- optional HA.

## Scope rule

Mỗi phase phải chứng minh product value trước khi mở rộng feature surface.
